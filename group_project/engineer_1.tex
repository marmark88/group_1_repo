\section{RNAsik: A Pipeline for complete and reproducible RNA-seq analysis that runs anywhere with speed and ease \cite{rnAsik2019}}

\paragraph{
    The RNAsik pipeline was successfully installed and executed by creating a dedicated Conda environment and installing the package from the available bioconda channel. Following installation, the pipeline was able to launch and display its usage and configuration options, confirming that the software itself was functional and correctly set up. However, full reproduction of the original test results described in the project documentation was not possible due to external data accessibility issues. Specifically, the pipeline relied on remote datasets hosted via HTTP/FTP links, which were either inaccessible (HTTP 403 Forbidden errors) or failed to resolve correctly when used within the execution workflow. Attempts to retrieve the required input data using the provided GitHub scripts were unsuccessful, preventing the pipeline from completing the intended test run. As a result, the exact computational workflow and expected outputs described in the documentation could not be replicated. This limitation appears to be unrelated to the core functionality of the RNAsik software itself and instead arises from external dependency and data-hosting availability issues. While the pipeline installation and command-line interface were verified as operational, a suitable substitute dataset was not identified within the scope of this work to enable full end-to-end replication. Therefore, the study can be considered partially reproducible in terms of software deployment, but not fully reproducible in terms of data results. Engineer: Mark Cubi
}

\section{SPEAQeasy: a scalable pipeline for expression analysis and quantification for R/bioconductor-powered RNA-seq analyses \cite{Eagles2021SPEAQeasy}}

\paragraph{
    The SPEAQeasy pipeline was successfully installed and executed within a Windows Subsystem for Linux (WSL2) environment using Docker and Nextflow. The workflow was able to initialize correctly, load the test dataset, and progress through multiple validation steps, including sample parsing, strand specification, and reference genome selection. However, full execution of the pipeline was not feasible on the available hardware due to system resource constraints. During runtime, the process failed at the genome assembly download and preparation stage, where the pipeline required approximately 4 GB of memory but only ~3.7 GB was available within the WSL2 environment. Despite attempts to adjust input parameters and execution profiles, the limitation persisted due to my local machine's total 8 GB RAM capacity and the additional overhead introduced by running a virtualized Linux environment alongside Docker containers. This indicates that while SPEAQeasy is functionally reproducible in terms of installation and configuration on the system, complete end-to-end execution of the full RNA-seq workflow is not feasible on my hardware. The results suggest that successful reproduction of the pipeline’s intended analysis requires a higher-memory computing environment, and that performance limitations rather than software incompatibility prevented full replication of the published workflow. Engineer: Mark Cubi
}
